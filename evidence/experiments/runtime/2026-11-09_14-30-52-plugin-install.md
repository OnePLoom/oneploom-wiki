# Codex 로컬 plugin 설치 시험

자료명은 관측에 사용한 근거를 식별한다. 개별 파일의 제공 범위는 [기록 기준](../../recording.md)을 따른다.

> 검토와 관측 기록. 검토 당시의 후보와 관측을 보존한다. 현재 채택 범위는 결정 목록에서 확인하며, 미실행 계획이나 예비 시험을 제품 검증 완료로 해석하지 않는다.

사용자 작업일: 2026-11-09. 대상: WSL의 Codex CLI 0.167.0. 이 디렉토리는 개인 시험 근거이며 배포 모듈 소스가 아니다.

## 입력과 범위

- 계획 기록: 모델 호출 없는 로컬 등록, 설치, 갱신, 제거 관측. Linux 임시 폴더의 예제 프로젝트와 자식 명령 전용 Codex 상태를 사용했다.
- 최초 스크립트 기록과 `input/`은 루트 manifest만 둔 최초 자료다. 호환 형식 재개 기록과 `compatibility/input/`은 `.codex-plugin/plugin.json`만 추가한 입력이다. 루트 manifest는 제거하지 않았다.
- 이전 자료 재설치 기록은 갱신된 자료로 재설치한 뒤 보존한 0.1.0 manifest로 되돌려 다시 설치하고 내용까지 대조한다. 자동 복구 기능을 구현한 것이 아니다.
- 실제 프로젝트의 AGENTS, Codex 설정, 개인 Codex 설정, marketplace와 시험 프로젝트의 AGENTS를 해시로 대조했다. 인증 파일을 복사하지 않았고 provider key 환경 변수도 명령에 전달하지 않았다. 다른 호스트 파일 전체를 추적한 검사는 아니다.

## 관측 결과

1. 최초 5개 명령 중 등록, 조회까지 성공했고 설치에서 `missing plugin.json`으로 실패했다. 파일은 실제 존재했다. 결과 기록, 설치 오류 기록.
2. 등록, 버전 확인을 반복하지 않고 변경 영향을 받는 목록 조회와 실패한 설치부터 재개했다. 호환 manifest 추가 뒤 설치, 재설치가 성공했고 재설치 전후 cache 내용은 동일했다. 재개 결과 기록.
3. 같은 ID의 원본 버전을 0.1.0 → 0.2.0으로 바꿔 재설치하니 목록도 0.2.0이 됐고 0.1.0 캐시 파일은 남지 않았다. 없는 이름은 종료 코드 1로 거부했고 제거 뒤 설치 목록, cache 파일은 비었다.
4. 보존한 0.1.0 자료를 다시 설치해 manifest 두 개와 skill 본문을 대조했다. 마지막에는 시험 plugin과 marketplace 등록을 제거했고 보호 대상 파일은 그대로였다. 복귀 결과 기록, 명령 기록.

전체 19개 명령에는 최초 설치 실패 1회와 의도한 없는 이름 오류 1회가 포함된다. 각 단계 stdout/stderr와 종료 코드를 보존했으며, 이 숫자를 기능 성공률이나 제품 품질 지표로 사용하지 않는다. `SHA256SUMS`는 이 디렉토리 기록의 저장 후 무결성 검사다.

## 한계와 다음 확인

- 실제 모델, skill 실행, native hook, 터미널 진입, private Git, 프로젝트별 버전 유지, 문서 마이그레이션을 시험하지 않았다. 모델 추론 호출은 0회다. CLI의 내부 네트워크 시도를 별도 계측한 결과는 아니다.
- 임시 상태 경로의 helper 실행 파일 생성 거부 경고가 있었으나 설치 명령은 동작했다. 이 경고를 무시해 실제 CLI 도구 호출까지 성공했다고 주장하지 않는다.
- 버전별 cache 경로의 존재가 여러 버전 보관이나 프로젝트별 버전 고정을 보장하지 않는다. 다음은 두 프로젝트의 버전 유지와 실제 CLI 연결이다.
- 문서상 형식 지원, 개인 배포 가능성은 [공식 패키징](https://developers.openai.com/plugins/build/plugins), 상태 위치 분리는 [환경 변수](https://learn.chatgpt.com/docs/config-file/environment-variables), hook 검토는 [Hooks](https://learn.chatgpt.com/docs/hooks)를 참고했다. 이 자료와 설치 버전의 실제 관측을 구별한다.
- 판단은 [설치 시험 — 「plugin 호환성 시험」](../../../design/runtime/install.md), 문제 추적은 [E-019 — 「E-019 — plugin 형식 호환과 갱신 캐시의 보존 범위」](../../issues.md)에 연결한다. 최종 설치 수단의 채택은 아직이다.
