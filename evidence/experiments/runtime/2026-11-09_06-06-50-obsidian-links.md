# Obsidian 제목 링크 보정

> 검토와 관측 기록. 검토 당시의 후보와 관측을 보존한다. 현재 채택 범위는 결정 목록에서 확인하며, 미실행 계획이나 예비 시험을 제품 검증 완료로 해석하지 않는다.

사용자 작업일: 2026-11-09. 디렉토리 시각은 UTC다. Obsidian 링크 보정, 검사 기준 수정과 ADR 0014 경계 채택 동기화의 근거이며 제품 구현 결과가 아니다.

## 입력과 변경

- 사용자 증상: architecture의 ‘모듈의 선택 확장과 실행 방식’ 링크가 문서 상단으로만 이동하고 제목을 찾지 못했다.
- 이전 검사기는 GitHub식 소문자, 하이픈 slug를 생성해 대조했다. 이번에는 실제 제목과 디코딩한 내부 링크를 비교한다. 공식 기준은 [Obsidian 내부 링크](https://help.obsidian.md/links)다.
- `audit.json`: 변경 전 59개 일반 Markdown의 제목 링크 373개 중 정규화 후보 371개. 이후 진행표 정리로 링크 목록 자체가 바뀌므로 최종 검사 분모와 구별한다.
- `apply.json`: 42개 문서의 내부 링크 주소 368개 보정. 코드 예시, 외부 URL을 일괄 치환하지 않았다.
- `links.py`: 사용한 조사/보정/검사 소스. 실행 시 `/tmp/harness-anchor-run`은 이 근거 디렉토리를 가리켰고 원본 위키 경로는 소스에 기록돼 있다. 배포 도구가 아니다.

## 확인

- `check.json`: 같은 검사기의 최종 결과. 실제 파일, 제목 확인이며 GUI를 자동 실행하지 않았다.
- `regression.json`: 실제 제목의 공백, 잘못된 slug, 실제 하이픈, 예약 문자, 코드 예시 제외, 링크 표기 처리의 7개 확인.
- `preservation.json`: 기존 제목 보존, 링크 외 본문 변경 허용 범위, 원시 근거, 초기 원자료 보존, 삭제 없음, 백업 SHA-256, 제품 추적 파일/index 무변경 확인.
- `before.json`: 수정 전 파일 해시. 위키 설정, 체크포인트는 변경 비교 대상에서 제외했다. 수정 전 백업은 2026-11-09 06:06:17 KST 생성 백업(식별자 `RzwjMQK5`)다.
- 사용자는 보정된 앵커가 정상 작동한다고 확인했다. 대표 링크의 GUI 확인이며 모든 링크 클릭이나 다른 렌더러 지원을 검증한 것은 아니다.

## 한계와 재개

과거 원시 실행 자료, 초기 초안 원문은 다시 쓰지 않았다. 그 안에 보존된 과거 링크/검사 결과는 당시 자료이며 현재 Obsidian 탐색 검사 범위와 구별한다. 사용자 보고와 검사 가정의 불일치는 문제 대장 E-018에 기록했다.

기본 메인, 단일 반영, 선택 보조 경계는 수용됐고 다음은 설치, 보존의 소유/Git 관리 협의다. 실제 설치, 충돌 차단, 복구, 병렬/로컬 모델 실행, 토큰 효과는 이번 확인에 포함하지 않는다.
