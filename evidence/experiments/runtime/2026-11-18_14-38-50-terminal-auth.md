# Windows 인증 화면 도달 관측

자료명은 관측에 사용한 근거를 식별한다. 개별 파일의 제공 범위는 [기록 기준](../../recording.md)을 따른다.

> 검토와 관측 기록. 검토 당시의 후보와 관측을 보존한다. 현재 채택 범위는 결정 목록에서 확인하며, 미실행 계획이나 예비 시험을 제품 검증 완료로 해석하지 않는다.

사용자 지정 작업일: 2026-11-18. [앞선 터미널 시험](2026-11-18_14-23-43-terminal-start.md)의 실제 사용자 재시도 후속이다. 최초 권한 오류, 당시 자동 검사와 원시 출력은 그대로 보존한다.

## 확인한 상태와 다음 순서

사용자는 명시적 workspace-write 재시도 안내 뒤 **“codex 입력화면 열리고, 계정 인증 화면이 나와”**라고 보고했다. 관측 기록 기록은 사용자 보고이며 화면/종료 코드를 도구로 직접 수집한 결과가 아니다.

따라서 이 조건에서는 앞선 즉시 종료를 지나 인증 화면까지 도달했다. 로그인 완료, 인증 후 프로젝트/권한과 모델, 실제 WIKI 읽기/쓰기, 같은 세션 재개는 아직 확인 전이다. 모든 사용자 설정에서 문제가 해결됐다고 확대하지 않는다.

다음은 Windows Codex의 `Sign in with ChatGPT`에서 사용자가 기존 구독 계정으로 로그인하고 시험 project 입력 화면으로 돌아오는지 확인하는 것이다. 설치된 Codex 0.169.1 패키지 README의 「Using Codex with your ChatGPT plan」에 따른 절차다. 인증은 사용자가 Codex에서 수행하고, 우리 시험 파일에 비밀값을 넣거나 WSL 인증 자료를 복사하지 않는다.

로그인 뒤 실제 경로를 확인한 다음 작은 합성 WIKI 읽기부터 진행한다. 아직 AI 요청을 입력하지 않도록 안내했다. 이번 관측 때문에 코드나 옵션을 다시 바꾸거나 통과한 자동 검사를 반복하지 않았다. 현재 설계 세션과 예비 WSL 도구는 유지한다.
