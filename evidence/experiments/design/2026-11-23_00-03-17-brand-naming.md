# 브랜드형 이름 추가 검토

자료명은 관측에 사용한 근거를 식별한다. 개별 파일의 제공 범위는 [기록 기준](../../recording.md)을 따른다.

> 검토와 관측 기록. 검토 당시의 후보와 관측을 보존한다. 현재 채택 범위는 결정 목록에서 확인하며, 미실행 계획이나 예비 시험을 제품 검증 완료로 해석하지 않는다.

## 범위와 상태

사용자 지정 작업일 2026-11-22. 제품의 정체성과 짧은 표기를 고려해 설명형 대안을 보존하고 브랜드형 후보를 비교했다. 현재 추천 ONPLIN, 대안 RENPLY 모두 미채택이다. 소유 원본은 [브랜드형 이름 후보](../../../design/module.md)이며 제품 명명/설치 문서의 예시와 실행 상태를 맞췄다.

## 조사와 판단의 경계

공개 웹 검색의 정확한 문자열은 Onplin, Renply, Onplio, Onpleo, Plenvo, Onprax, Selvra, Nuvren, Onpli, Opryn이었다. Onplin과 Renply는 software/company 및 GitHub/PyPI/npm 도메인을 조합한 검색도 했다. 뚜렷한 동명 개발 서비스는 확인하지 못했으나 패키지 API, 도메인 등록과 상표 조회는 수행하지 않았다. 이전 Condharness/Harnesslane의 조회 결과를 새 후보에 적용하지 않는다.

Renply는 게임 닉네임 [검색 결과](https://mapleranks.com/u/Renply)가 있어 모든 문자열 사용의 부재를 주장하지 않는다. 기존 사용이 확인된 [Plenvo](https://www.plenvo.io/), [Opryn](https://www.opryn.app/), [ONPLI](https://onpli.org/)는 최종 추천에서 제외했다. 명칭 사용 관측이며 업체의 품질이나 법적 권리를 판정한 것이 아니다.

ONPLIN과 RENPLY 등의 창작명을 비교했다. 발음과 디자인 인상은 제안이며 측정 결과가 아니다. 외부 로고/문구/코드를 복제하거나 이름 예약/등록을 실행하지 않았다. 브랜드/제품/명령 표기를 불필요하게 복잡하게 나누지 않는 방향으로 검토했다.

## 검증과 재개

문서/보존 결과 기록, 현재 상태 기록, 체크섬 기록을 참조한다. 검사 코드 기록은 수정 범위의 링크/제목/형식과 기존 파일/제품/Git/닫힌 근거 보존을 확인한다. 변경 없는 JSON 예시의 이전 PASS만 재사용한다.

다음은 이름 선호를 좁힌 뒤 등록/유사 명칭 검토와 기본 설치 위치 선택을 연결하는 것이다. 실제 제품 구현, Git 작업, Windows 실행, 추가 AI 실험은 없다. 기존 기본 설치 원칙이나 예비 WSL 도구를 변경하지 않았다.
