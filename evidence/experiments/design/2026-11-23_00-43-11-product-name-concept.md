# 제품 전체의 의미를 반영한 이름 후보

자료명은 관측에 사용한 근거를 식별한다. 개별 파일의 제공 범위는 [기록 기준](../../recording.md)을 따른다.

> 검토와 관측 기록. 검토 당시의 후보와 관측을 보존한다. 현재 채택 범위는 결정 목록에서 확인하며, 미실행 계획이나 예비 시험을 제품 검증 완료로 해석하지 않는다.

사용자 지정 작업일은 2026-11-22다. 작업 전 백업은 2026-11-23 00:40:54 KST 생성 백업(식별자 `xSaK6Fs9`)다. 부모는 4단계 파일별 변경 명세이며 이름과 기본 설치 위치는 여전히 미선택이다.

## 요청과 판단

사용자는 이전 이름들이 선택적 조건부 하네스, 로컬 WIKI 연동, 코드와 커밋 근거의 복원, 이후 지속 사용이라는 전체 의미를 충분히 담지 못한다고 보았다. 기존 [제품의 중심과 도입 경로](../../../design/architecture.md)를 확인하고 [브랜드형 이름 후보](../../../design/module.md)를 보완했다. 제품 기능이나 도입 순서를 새로 채택한 것은 아니다.

의미 적합성 추천은 OnepLoom이다. OnepLoop, OnepLore, OnepRelay와 비교했고 새 이름의 독자성과 사용 가능성은 별도 확인 대상으로 남긴다. [Schacht의 구성품 설명](https://schachtspindle.com/blogs/product-diagrams/standard-floor-loom-shaft-harness-parts)은 실제 직조기에서 harness라는 단어를 사용한다는 근거다. 소프트웨어 용어의 어원을 증명하는 출처로 사용하지 않는다. [Atlassian의 Loom](https://www.atlassian.com/software/loom)이 존재하므로 기존 서비스와의 연상은 명명 비용으로 기록한다.

## 이름 조회와 한계

조회 코드 기록으로 공개 API 12건을 읽었다. 원시 결과 기록에서 네 후보의 GitHub 저장소 이름 검색은 각각 0건이고 incomplete_results는 false다. PyPI와 npm의 해당 패키지 이름 조회는 각각 404였다. 이번 결과를 이전 후보의 조회와 섞지 않으며 저장을 위해 조회를 반복하지 않았다.

정확한 전체 이름의 공개 웹 검색에서도 뚜렷한 사용 결과를 찾지 못했지만, 도메인/상표/유사 명칭/비공개 저장소/개인 명령까지 없다는 뜻은 아니다. 이름 등록, 법적 사용 가능성 판정, 패키지 설치나 배포 방식 변경은 수행하지 않았다.

## 확인 범위

소유 문서의 현재 후보, 진행표와 active를 함께 갱신하고 이전 후보와 닫힌 근거를 보존했다. 문서 수정 중 두 번의 패치 문맥 불일치는 쓰기 전에 거부됐으며 실제 문단을 다시 읽고 해당 절을 교체했다. 제품 코드나 계약의 변경은 없다.

정적 검사 기록은 링크/제목, 변경 범위, 제품 원본과 닫힌 근거의 보존을 확인한다. 상태 기록과 체크섬 기록에 결과를 남긴다. 이 검사는 이름 채택, 로고 제작, 실제 Windows 실행이나 모델 효과의 검증이 아니다. 새 AI 요청과 Git commit/push는 없다.
