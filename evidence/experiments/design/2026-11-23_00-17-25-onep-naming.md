# onep를 사용한 제품 이름 후보

자료명은 관측에 사용한 근거를 식별한다. 개별 파일의 제공 범위는 [기록 기준](../../recording.md)을 따른다.

> 검토와 관측 기록. 검토 당시의 후보와 관측을 보존한다. 현재 채택 범위는 결정 목록에서 확인하며, 미실행 계획이나 예비 시험을 제품 검증 완료로 해석하지 않는다.

사용자 지정 작업일은 2026-11-22다. 부모는 4단계 파일별 변경 명세이며 이름과 기본 설치 위치는 아직 사용자 선택 전이다.

## 요청과 판단

제품의 식별성과 제공 기능을 함께 드러내는 후보를 비교했다. 현재 채택은 [제품 이름과 변경 기준](../../../design/module.md)에 연결한다.

현재 추천은 OnepGate, 상징성을 우선하는 대안은 OnepWeave다. OnepForge와 OnepFlow도 비교했으며 이전 ONPLIN과 RENPLY는 현재 추천에서 제외했다. 이름이나 제품 위치를 채택하거나 구현한 것은 아니다.

## 이름 조회와 한계

원시 결과 기록은 네 후보의 GitHub 공개 저장소 이름 검색, PyPI와 npm의 정확한 패키지 이름 조회 결과 12건이다. GitHub는 각 0건이며 `incomplete_results`는 false, 두 패키지 저장소는 각 404였다. 조회 코드 기록은 읽기 전용이며 등록과 인증 정보 사용은 없다. 첫 sandbox 조회는 DNS 실패였고 외부 실행 승인을 받은 재조회가 완료됐다. 결과 파일은 완료한 재조회의 반환을 보존한 것이며 기록을 위해 다시 요청하지 않았다.

공개 웹 검색에서 OnepFlow와 같은 닉네임 사용이 검색됐다. 유사 철자의 [Oneflow](https://oneflow.com/)는 계약 관리 서비스를 제공한다. 따라서 문자열 전체가 처음 사용되거나 유사 브랜드가 없다고 보지 않는다. 공개 검색과 패키지 부재는 도메인, 상표, 비공개 저장소, 로컬 명령의 충돌 부재나 등록 가능성을 증명하지 않는다. 실제 이름 등록과 법적 사용 가능성 판단은 이번 범위가 아니다.

## 작명 사례

[Python 공식 FAQ](https://docs.python.org/3/faq/general.html#why-is-it-called-python)는 이름이 Monty Python에서 왔다고 설명한다. [uv 공식 문서](https://docs.astral.sh/uv/)는 제품 uv와 제공자 Astral을 구분한다. 저자 이름을 반드시 제품명에 사용해야 한다는 근거로 보지 않으며 업계 전체의 작명 비율을 추정하지 않는다.

## 확인 범위

당시 후보와 미채택 상태를 관련 제품 명명/설치 문서와 대조했다. 현재 이름은 위 제품 이름 문서의 후속 결정을 따른다. 문서 규칙이나 제품 계약을 바꾼 것은 아니다. 정적 검사 결과 기록은 내부 링크와 제목, 변경 범위, 기존 제품 파일과 닫힌 근거의 보존을 확인한다. 변경 없는 실행기 JSON 예시의 이전 검사만 재사용하며 이름 검토를 Windows 기능 검증으로 확대하지 않는다.

상태 기록과 체크섬 기록에 이번 기록의 완료 여부와 무결성을 남긴다. 제품 설치, 모델 호출, 로고 제작, Git 저장소 생성이나 commit/push는 수행하지 않았다.
