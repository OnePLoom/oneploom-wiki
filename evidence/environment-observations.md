# 예비 환경 연결의 관측

제품 구현 전에 경로 접근과 문서 보존의 성립 여부를 확인한 예비 관측이다. 제품의 전체 설치/복구 성공이 아니다.

## 확인한 것

- WSL 경로 변환과 Codex 시작/재개 인자 파싱의 격리 검사 21개. 모델 호출 없이 `--preview`/`--help`를 사용했으며 dummy UUID를 실제 세션 복구로 해석하지 않았다.
- Windows 문서 사본의 양방향 수정, 이름 변경, 열린 Obsidian의 반영과 재열기 후 보존. 파일 검사와 사용자 GUI 관측을 구분했다.
- 내부 Markdown 파일/제목 링크, 외부 파일 링크와 vault 경계의 차이. 파일 존재만으로 실제 앱 클릭 성공을 판정할 수 없다.
- 실행 상태 경로를 공유 지식과 분리하고 `.harness/` 전체의 Git 제외를 검사하는 방향. 기존 특정 도구의 연결 성공을 새 설치기의 자동 연결 성공으로 확대하지 않았다.

## 확인하지 못한 것

초기 WSL vault 열기 오류의 정확한 원인/재현, 일반 사용자 전체의 호환성과 성능, 완성된 제품의 설치/시작/복구는 이 관측으로 보장하지 않는다. Windows 직접 실행과 실제 사용자 흐름은 [제품 수용 기준](../verification/acceptance.md)에서 별도로 검증한다.
