# 초기 검토와 변경 이력

초기의 제안과 설명은 당시의 판단 기록이다. 구현된 사실이나 현재 계약으로 읽지 않는다. 특히 예제 설정, 추정 효과와 당시 미검증 후보는 현행 설계/ADR로 다시 확인한다. 현재안에 맞춰 과거 실패와 반론을 삭제하지 않는다.

- [초기 질문과 답변](questions.md): 조건부 구조, 로컬 AI, 도구/설정 분리에 관한 초기 논의.
- [기존 하네스 구조 초안](initial-architecture.md): 감사 전 단계의 구조 설명과 개선 가설.
- [이식과 역공학 초안](initial-portability.md): 프로젝트별 매핑과 재사용, 지식 복원의 초기 제안.
- [설치 방식 비교](install.md): plugin/외부 실행본/프로젝트 설치의 장단점과 전환.
- [문서 위치표 비교](map.md): JSON 단일/분할/역할 구성과 유지보수 판단.

현재 채택과 대체 관계는 [ADR 전체 목록](../../decisions/README.md), 실제 비교는 [근거](../../evidence/README.md)로 연결한다.
